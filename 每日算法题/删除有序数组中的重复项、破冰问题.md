题目一：【删除有序数组中的重复项】https://leetcode.cn/problems/remove-duplicates-from-sorted-array/description/         腾讯云智 2024 后端开发

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int i = 0, j = 1;
        for(i = 1; i < nums.size(); i++) {
            if(nums[i - 1] != nums[i])
                nums[j++] = nums[i];
        }
        return j;
    }
};
```



题目二：【破冰问题】https://leetcode.cn/problems/yuan-quan-zhong-zui-hou-sheng-xia-de-shu-zi-lcof/description/?envType=problem-list-v2&envId=recursion      深信服 2023 后端开发

```cpp
class Solution {
public:
    int iceBreakingGame(int num, int target) {
        int f = 0;
        for(int i = 2; i <= num; i++)
            f = (f + target) % i;
        return f;
    }
};
```
